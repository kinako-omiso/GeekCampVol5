# Scannee's Summit デザイン(案2「そらの てっぺん」)

画面の見た目・演出・言葉づかいの正解はこのフォルダです。仕様書(ゲームのルールと数値)と食い違うところは「仕様書との差分」にまとめています。

## このフォルダの使い方

- **人が見るとき**:`screens/index.html` をブラウザで開く。各画面はアニメーション付きで動きます。
- **AI(Claude Code / Codex / Gemini)が実装するとき**:
  1. この README を読む
  2. 実装する画面の `screens/*.html` を**その画面の分だけ**読む
  3. 色・フォント・線は `tokens.css`(TS からは `tokens.ts`)を使う
  4. アイコンや目の表情は `assets/` の SVG を使う
  - `source/` は読んでもよいが、コードにコピーしない(独自記法が入っている)

```
docs/design/
├─ README.md          このファイル
├─ AGENTS-snippet.md  AGENTS.md に貼る文
├─ tokens.css         色・フォント・線・影・ボタン・共通アニメーション
├─ tokens.ts          同じ値の TS 版(Babylon の色、演出の秒数、目の表情の対応)
├─ screens/           全画面の見本(ブラウザで開ける HTML)
│   ├─ index.html     画面一覧
│   ├─ pc-01〜10      PC(/host)
│   ├─ phone-01〜08   スマホ(/controller)。1P/2P と各状態を縦に並べてある
│   │                 (06 おてほん、07・08 は縦持ち案)
│   └─ style.html     スタイルボード
├─ assets/
│   ├─ eyes/          Scannee の目 10種
│   ├─ icons/         アイコン 31種(currentColor)
│   └─ *.svg          雲・島・旗・王冠・ドカッの星・おひさま・山・拍手・矢印・見本のコマ など
└─ source/            デザインキャンバスの元データ(参照用)
```

## コンセプト

**雲の上に浮かぶ山のてっぺんで、目のついたモノ「Scannee」どうしが押し合う。**
名前の *Summit*(てっぺん)をそのまま世界にして、ルールを全部「見た目の出来事」にしている。子どもが説明を読まなくても分かることが最優先。

| ゲームのルール | 画面での見せ方 |
|---|---|
| スキャンしたモノ | 目がついて Scannee になる。目が向いている方が「まえ」 |
| のれる範囲(有効半径) | 草の島。外は雲 |
| リング縮小 | 雲がせまってくる。予告中は草のふちが赤いしましまで点滅+真ん中を指す矢印+「まんなかへ にげて!」 |
| 場外 | 山から「おっこちた!」→ 雲に「ポフッ」 |
| HP | ハート+大きい数字+バー(画面上部) |
| 時間切れ | 残りHPの高さの山が生えて「たかい ほうが かち!」 |
| KO | 負けた側が空へ飛んで「キラーン!」 |
| 勝ち | てっぺんで王冠・キラキラ目、うしろに長い旗。負けた側は小島で拍手 |

### 3つの原則

1. **色で自分が分かる**:1P は青、2P は赤。リング・HP・スマホの背景・旗・枠すべて同じ色。PC では 1P が常に左、2P が常に右。
2. **文字より絵と数字**:ひらがな中心、1画面に1メッセージ。白い大きな字には必ずふちどり。
3. **はでなのは登場・VS・決着・かちだけ**:対戦中は見やすさを優先して落ち着かせる。

## PC(/host)の作り方

- **1280×720 のステージを拡大縮小する。** 見本はすべて 1280×720 の固定座標。ゲーム画面なので、ステージごと `transform: scale()` で画面に合わせればよい(比率は固定、余った所は `--ss-sky`)。

  ```tsx
  // 例: 1280×720 のステージを画面に合わせる
  const scale = Math.min(window.innerWidth / 1280, window.innerHeight / 720);
  <div style={{ width: 1280, height: 720, transform: `scale(${scale})`, transformOrigin: '0 0' }}>…</div>
  ```

- **下に Babylon の canvas、上に React のオーバーレイ。** PC はプレイヤーが触らないので、オーバーレイは `pointer-events: none`。
- **3D にするもの(案)**
  - 浮島(草の円盤+崖)と雲海
  - 縮小:有効半径の外を雲で覆う。物理は仕様どおり衝突フィルタのまま、見た目も同じ「有効半径」の値を参照する
  - プレイヤーリングと向きの三角(リングの前側に付ける)
  - Scannee 本体と目(下の「Scannee の目」)
- **2D のままでよいもの**:HUD、「まんなかへ にげて!」、ドカッ!、KO! などの文字演出、カード類、時間切れの山くらべ。
- **縮小予告の矢印**:赤いしましまの上に、真ん中を指す白い矢印(`assets/move-in.svg`)を4つ置いて内側へ動かす。3D の床に貼っても、2D で重ねてもよい。
- **カメラ**:仕様どおり斜め俯瞰・方位角固定。見本の楕円(横:縦 ≒ 1.6:1)は見え方の目安。

## スマホ(/controller)の作り方

- **横持ち固定。** 844×390 は基準サイズで、実機では `100dvw × 100dvh` の中を flex / grid で組む(absolute の座標はそのまま使わない)。ノッチ側は `env(safe-area-inset-*)` で逃がす。
- **背景はプレイヤー色**(`players[id].main`)。見本の 1P/2P の違いは色とコマだけ。
- **対戦ボタン**は左右いっぱい。A は左の親指、B は右の親指の下。押したら下に沈む(`.ss-button.is-pressed`)。
  - B は 3秒のクールダウンを暗い扇形(conic-gradient)+残り秒で見せ、戻ったら内側がピカッと光る。
  - 振動できない端末(iPhone)は被弾時に画面を白く点滅させる。
- **状態の流れ**(見本では縦に並べてある)
  - 接続:はじめ →(タッチでモーション権限を要求)→ 基準姿勢の取得中 → OK
  - スキャン:撮影 → ぬりぬり → 送信中 → 送信完了(「とりなおす」で撮影へ戻る、「おてほん」でプリセット選択へ)
  - おてほん:6体から選ぶ →(これに する!)→ きまり! PCを みてね!(「もどる」でスキャンへ)。プリセットはアプリに入っているデータで、写真アプリの許可はいらない
  - 向き調整:調整中 →(けってい)→ 相手待ち
  - けっか:えらぶ →(タップ)→ 相手待ち
- iOS では権限ダイアログの「許可」を押す必要があるので、接続画面で案内している。
- ボタンは必ず `<button>` にして、アイコンだけのものには `aria-label` を付ける。

## Scannee の目

目の表情で「今どういう状態か」を見せる。文字や HP バーを見なくても、誰がやられたか・溜めているかが分かる。

| 場面 | 表情 | ファイル |
|---|---|---|
| ふだん(見ている方が「まえ」) | ふつう | `eyes/look-right.svg` / `look-left.svg` |
| 登場で着地するまで → 着地でパチッ | とじる → ふつう | `eyes/shut.svg` |
| Bの予備動作・VS | キリッ | `eyes/angry-right.svg` / `angry-left.svg` |
| 被弾(白点滅と同時) | いたっ | `eyes/hurt.svg` |
| KO | ぐるぐる | `eyes/dizzy.svg` |
| 勝ち | キラキラ | `eyes/star.svg` |
| 準備完了・負けたあとの拍手 | にっこり | `eyes/happy.svg` |
| 山くらべで負け | しょんぼり | `eyes/sad.svg` |
| 切断中 | すやすや | `eyes/shut.svg` |

`tokens.ts` の `eyeFor` に同じ対応を入れてある。

- **3D での付け方(案)**:正規化後のメッシュの前面(輪郭を押し出した面)の、中心より少し上に目の板を少し浮かせて貼る。見本では目2つぶんの幅が前面の幅の半分〜6割くらい。テクスチャは `assets/eyes/*.svg` をラスタライズして使い、表情はテクスチャの差し替えで変える。
- 2D(HUD の顔アイコンなど)では SVG をそのまま重ねる。

## デザイントークン

- 色・フォント・線・影はすべて `tokens.css` の変数を使い、コンポーネントに直書きしない。
- Babylon では `tokens.ts` の値を `Color3.FromHexString(colors.grass)` のように使う。
- **ふちどり文字**は `-webkit-text-stroke` + `paint-order: stroke fill`。線は半分だけ外に出るので、見た目の太さの2倍を指定する(`.ss-outline-l/m/s`)。
- フォントは Mochiy Pop One(見出し・数字・かけ声)と M PLUS Rounded 1c の 800/900(ボタン・説明)。

## 素材(assets)

- `icons/` は `currentColor` で描いてある。インライン SVG か SVGR(`vite-plugin-svgr`)で React コンポーネントにすると、CSS の `color` で色が変わる。`<img>` で使うと黒になる。
- `flag.svg`・`flag-tall.svg`(勝利画面の長い旗)の布も `currentColor`。プレイヤー色を `color` で渡す。
- `mountain-p1/p2.svg` は勝利と時間切れで共通の山。上が平らで広い(y=44 がてっぺんの面)。時間切れでは HP に合わせて上下させる。
- `summit.svg` はロビーの真ん中の山、`clap.svg` は負けた側の拍手、`move-in.svg` は縮小予告の矢印、`go-center.svg` は「まんなかへ にげて!」のアイコン。
- `sample-scannee-*.svg` は見本用のコマ。本番のコマはスキャン結果。block / milk / donut / star はおてほん画面の見本。

## 仕様書との差分・未決事項

1. **Scannee に目を付ける。** 仕様書には「コマ自体には着色しない」とある。目は色を塗るのではなく上に貼るものとしているが、チームで確認する。
2. **2P の色を `#E8284F`(少しピンク寄りの赤)にした。** 空の青と区別しやすくするため。
3. **HP・タイマーを画面上部に置いた。** 1対1の格闘ゲームの定番で、アリーナの手前を隠さない。
4. **スマホに「けっか」画面を新規追加した。** 再戦の2択を各自がタップで選び、PC に選択状況を出す。2人の選択が食い違ったとき(片方だけ再スキャン)の扱いは未決。
5. **スキャンの領域指定を「なぞる」から「ぬりぬり」にした。** Interactive Segmenter の scribble 入力を想定。「ぬる/けす」で追加・除外。撮影画面にコツ(1こだけ・あかるく・まるごと)を出す。
6. **基準姿勢の取得を水準器の泡で見せる。**
7. **決着の見せ方**:KO は「キラーン!」、場外は「おっこちた!」、時間切れは山くらべ。
8. **キャッチコピー**を「もってる モノで てっぺんへ!」にした。
9. **プリセットを「おてほん」と呼び、選ぶ画面を新規追加した。** 見本は6体(マグカップ・けしゴム・つみき・ぎゅうにゅう・ドーナツ・ほし)。中身(形のデータ・能力値)は未決。
10. **スキャンだけ縦持ちにする案を置いた(phone-07・08)。** 仕様書は横持ち固定。採用するなら、スキャン後に横持ちへ戻す案内が要る。
11. **PC の HUD には B のクールダウンを出さない。** スマホのボタンで見せる。
12. **決着の暗転ストップ(0.7秒)は演出用。** 対戦中のヒットストップ(0.05秒)とは別物。
13. **見本の数値はサンプル。** HP(72/41、38/21 など)、能力の★の数、タイプ名。★は倍率 0.80〜1.25 を5段階に分ける想定。タイプ名は一番高い能力値から決める案。

## source/ について

デザインキャンバス(claude.ai の「Scannee's Summit UI/UX 案2」)の元データ。

- `.dc.html` は `{{…}}` や `<sc-if>` などキャンバス専用の書き方で、ブラウザでは表示されない。
- スマホ画面の状態の切り替え方は、各ファイル末尾の `<script>` の `renderVals()` を見ると分かる。
- コードには写さず、`screens/` の見本と `tokens` から作る。

## Claude Code への頼み方(例)

> `docs/design/README.md` と `docs/design/screens/phone-04-battle.html` を読んで、/controller の対戦画面を `features/controller/battle` に作って。色と線は `docs/design/tokens.css`、アイコンは `docs/design/assets/icons` を使って。1P/2P は props で切り替え。

> `docs/design/tokens.css` をアプリの共通スタイルとして読み込めるようにして、`tokens.ts` を `src/` から import できる場所に置いて。

> `docs/design/screens/pc-06-battle.html` の HUD 部分(上のHP・タイマー・「まんなかへ にげて!」)だけを、Babylon の canvas の上に重ねる React コンポーネントにして。数値は props で受け取る。

`features/` 以下のディレクトリ名は例。実際の構成に合わせてよい。
