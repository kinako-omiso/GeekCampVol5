# Issue #32：Visual Hull 品質評価

## 撮影条件

対象物を中央に置き、カメラの距離と高さをおおむね固定する。正面・右・背面・左を必ず撮影し、可能なら斜め4方向を加える。写真ごとにMaskと方位角を確認する。撮影条件と処理時間は再現できるように記録する。

## 合成Maskでの検証

`npm run test:visual-hull -w packages/web` で、箱型の4視点・8視点と円形の8視点を確認する。96³の復元、閉じた面、法線、正の体積、`geometry-wasm` への接続、空Maskと不正な姿勢を自動テストする。これは実物の認識しやすさを評価するものではない。
