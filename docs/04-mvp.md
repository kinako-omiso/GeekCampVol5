# 最小構成（MVP）

## MVPのゴール
スマホで物を撮ると、その形から能力値を持ったコマができて、傾け操作で対戦して決着がつく

### MVPとしての判断基準
この機能が無いとデモが成立しないかどうか

## 画面構成
**PC（/host）**
 
| 画面 | MVP の内容 | 完成形との差 |
|---|---|---|
| ロビー | QRコード2つ、接続状態 | 準備状況の細かい表示なし |
| スキャン | 両者の進捗（転送中／解析中／完了） | 直列処理の待機表示は簡易でよい |
| 対戦 | アリーナ、HPバー、残り時間、**能力値の常時表示** | リング縮小の予告なし |
| 結果 | 勝敗と最終HP | 勝ったコマのアップ、再戦の2択なし |
 
**スマホ（/controller）**
 
| 画面 | MVP の内容 | 完成形との差 |
|---|---|---|
| 接続 | センサー有効化、基準姿勢の取得 | 差なし |
| スキャン | 撮影、領域指定、転送の進捗 | やり直しボタン、プリセット選択なし |
| 対戦 | AボタンとBボタン | 接続状態の表示は簡易でよい |
 
## 能力値をどこに出すか(仮案)
完成形では登場演出で大写しにするが、MVP では**対戦画面の HPバーの隣に常時表示**する。
 
```
P1  ぼくの消しゴム        P2  マグカップ
HP ████████░░ 128        HP ██████░░░░ 110
攻 1.05  リーチ 1.01      攻 1.20  リーチ 0.89
旋回 192  移動 0.89       旋回 228  移動 1.02
```
 
これで「形が強さになっている」が伝わる。**演出がなくても企画の核は死なない。**

### MVPから外さない機能
| 機能 | 外せない理由 |
|---|---|
| 能力値の生成 | **これが無いと企画そのものが消える** |
| 輪郭の RDP 0.2% 単純化 | これが無いと鋭さの項目が壊れる
| 最大連結成分の抽出 | 手や影が混ざると形が別物になる |
| プレイヤーカラーのリング | 同じ物をスキャンすると見分けがつかない。実装は床に円を置くだけ |
| 場外判定 | 1行で書けるうえ、無いとコマが永遠に落下する |

### チェックリスト
 
- [ ] スマホ2台がQRで接続できる
- [ ] スマホで撮った写真からコマが生成される
- [ ] コマごとに能力値が違う（同じ物なら同じ値になる）
- [ ] 能力値が対戦画面に表示される
- [ ] 傾けるとコマ2つがそれぞれ動く
- [ ] A/Bボタンで突進する
- [ ] HP・場外・時間切れのいずれかで決着する
- [ ] 接続から決着までを5分以内に通せる
- [ ] iPhone と Android の両方で動く
- [ ] 通しで1回、**デモ動画が撮れる状態になっている**

## MVP以降に実装するもの

| 順 | 項目 | 効果 |
|---|---|---|
| 1 | **被弾のヒットストップ・白点滅** | 試合が格段に見やすくなる。デモの質に直結 |
| 2 | **プリセットコマ** | スキャン失敗時の保険。本番前には必須 |
| 3 | **登場演出** | デモ動画の見せ場。ここが一番「おお」となる |
| 4 | ear clipping への差し替え | 描画の破綻を直す |
| 5 | リング縮小（予告つき） | アリーナ固定からの格上げ |
| 6 | 効果音 | 命中・場外・カウントダウン |
| 7 | 向き調整画面 | 自動決め打ちで不満が出た場合のみ |
| 8 | 再戦の2択 | デモで2試合見せるなら欲しい |
| 9 | 触覚フィードバック | あると気持ちいい |
| 10 | 切断時の一時停止 | 本番の事故対策 |
