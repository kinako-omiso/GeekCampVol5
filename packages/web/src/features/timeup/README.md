# timeup
PC：時間切れの山くらべ。決着の演出（タイムアップ!）のあと、残り HP の高さの山で勝ち負けを見せる。

- `TimeUpScreen.tsx`：山くらべの画面。コマの見た目・HP・勝者（null なら引き分け）を props で受け取り、1回だけ再生する。見本は docs/design/screens/pc-09-timeup.html
  - 勝ちのときは終わったら `onDone` を呼ぶ（結果画面へ）。引き分けは「スマホで つぎを えらんでね」を出したままこの画面で待つ
  - 山の高さは、HP が多い側を見本の勝った山の高さにし、もう一方を HP の比で低くする（見本は HP 1 あたり約 8.5px の固定比率だが、最大 HP 110〜128 でははみ出すため）
