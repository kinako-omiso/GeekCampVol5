# Issue #49：生成モデルの配置・対戦検証

## 起動と作成

ルートで `npm run dev` を実行し、PCのWebGL2対応ブラウザで `/dev/visual-hull` を開く。正面・右・背面・左の写真を4枚まとめて取り込むか、方向を選んで1枚ずつ取り込む。一括取込では写真一覧から正面を選び、対象物を指定すると残りの方向のMask候補が生成される。個別取込では点・ストロークで対象を指定して「修正を反映」を押す。

写真・Maskを確認し、必要なら追加・除外を反映して「Visual Hullを生成」を押す。「配置調整へ進む」で生成モデルを確認する。生成に失敗した場合や解析できない場合は、表示されたエラーを確認する。解析結果のない既存JSONは、この操作時に既存のgeometry-wasmで解析する。

「8方向・検証の詳細」を開くと、斜め4方向、4〜8枚の取込、CPU/GPU・Worker比較、生成方式、保存・再読込、Voxel断面と計測を使用できる。写真とMaskの計測値は写真パネルの詳細にある。詳細を閉じても任意方向の写真は保持され、生成に使用される。

## 配置と操作

初期配置は正面写真の方向・モデル最下端から自動設定する。青いマーカーは攻撃方向、水色の面は接地面、黄色の点は生成時の重心を表す。正面補正、足元に対する水平位置X/Z、生成座標系の下端Yを変更できる。下端より下は衝突から除外し、表示する形はそのまま残す。上下方向と縮尺・重心・能力値は再計算しない。

閲覧時のドラッグ・ホイールはカメラ操作であり、対戦に保存する補正には影響しない。「自動設定に戻す」で補正を戻せる。「この配置で対戦を確認」を押すと、1Pは生成モデル、2Pは既存Quick Scanサンプルになる。

| プレイヤー | 移動 | 検証攻撃 | 命中時の追加インパルス |
|---|---|---|---:|
| 1P・青 | W/A/S/D | F | 2.4 |
| 2P・赤 | 矢印キー | Enter | 3.9 |

攻撃キーの長押しで連続入力しない。Enterの前はキャンバスにフォーカスする。「最初から試す」は確定したモデル・補正で対戦だけを再初期化する。「配置調整へ戻る」「モデル作成へ戻る」で写真・Mask・モデル・補正値を保持する。モデル再生成・差し替え時は補正を初期化する。補正値はページ内だけに保持され、既存JSONには保存しない。

## 確認ケース

| 操作 | 期待結果 |
|---|---|
| 4方向を一括または個別に取り込み、生成→配置→対戦へ進む | 作成したモデルが1Pとして表示され、2Pは既存サンプルになる |
| 正面角と水平位置を補正し、対戦へ進む | 同じ見た目と足元位置で配置され、前方マーカーに沿って攻撃する |
| 下端を少し上げて対戦へ進む | 指定した面が床に接地する。表示モデルは床下に残り、その部分は床・相手との衝突から除外される |
| 下端をモデル最上端へ設定する／数値を空にする | エラーが表示され、対戦開始が無効になる。戻って再び調整するか自動設定に戻せる |
| 攻撃なしで接触する | 押し合い、接触回数だけが増える |
| 正面を相手へ向け、接近してF／Enterを押す | 命中が1回増え、追加インパルスで押し戻す。攻撃側は復帰する |
| Aで1Pを場外へ動かす | 1Pだけ場外となり落下する。元のモデルの下部も表示される |
| 再初期化する | 同じモデルと配置で始まり、命中・接触・場外表示が初期化される |
| 配置／作成へ戻る | 補正・写真・Maskが保持され、作成画面の写真とMaskも再描画される |
| 再生成・JSON再読込する | 配置が自動設定へ戻り、古い配置で対戦しない |
| 詳細を閉じて再度開く | 写真・Mask・計測結果を保持する。初回描画の計測回数が増えない |
| `/dev/physics` と `/dev/photo-model` を開く | 既存のサンプル2体検証とQuick Scanが使える |
