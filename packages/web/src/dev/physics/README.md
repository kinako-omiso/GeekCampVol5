# Issue #6：PC実機テスト手順

`/dev/physics` は、Quick Scanのサンプル形状2体を使った衝突・攻撃ノックバック・場外判定の検証画面。PCのキーボードとWebGL2対応ブラウザで確認する。スマホ接続は不要。

## 準備

1. リポジトリのルートで、依存関係が未インストールなら `npm ci` を実行する。
2. ルートで `npm run dev -w packages/web` を実行する。表示されたURLの末尾に `/dev/physics` を付けてPCのブラウザで開く。通常は `http://localhost:5173/dev/physics`。別のポートが表示された場合はそのポートを使う。
3. Vercel Previewを確認する場合は、デプロイ後のPreview URLの末尾に `/dev/physics` を付け、同じPCブラウザで開く。
4. 「2体の衝突と場外を確認できます。」が表示されるまで待つ。初期化エラーがないこと、左に青い足元リングの1P、右に赤い足元リングの2P、床と外周リングが見えることを確認する。

| プレイヤー | 移動 | 検証用の体当たり | 固定攻撃値 | 固定攻撃力倍率 | 命中時の追加インパルス |
|---|---|---|---:|---:|---:|
| 1P・青 | W/A/S/D | F | 1.0 | 0.8 | 2.4 |
| 2P・赤 | 矢印キー | Enter | 1.0 | 1.3 | 3.9 |

Enterを押す前に「最初から試す」ボタンからフォーカスを外す。キャンバスを一度クリックすると確実。各ケースは特記がなければ「最初から試す」を押し、初期化完了を待ってから始める。F／Enterは正面への攻撃なので、足元リングの前方マーカーを相手へ向ける。前進と命中受付は0.1秒。命中時または攻撃開始から0.1秒後に復帰を始め、0.2秒かけて攻撃前の位置へ戻る。再攻撃までの最小間隔は0.4秒。復帰位置を確かめるときは移動キーを離す。

## 確認ケース

| No. | 操作 | 期待結果 |
|---:|---|---|
| 1 | 1PはD、2Pは左矢印で近づけ、攻撃キーを押さずに接触させる。 | 2体がすり抜けずに押し合い、「コマ同士の接触開始」が増える。両者の「命中」は0回のまま。 |
| 2 | 2体を衝突直前まで近づけ、1Pが相手の正面へFで体当たりする。両者の移動キーは命中直後まで押し続け、復帰を見る前に離す。 | 1Pの命中が1回増え、直近の追加インパルスは2.4。2Pが1Pから離れる方向へ押し戻され、1Pは一緒に前進し続けず、攻撃前の位置へ滑らかに戻る。 |
| 3 | 同じ条件で2PがEnterで体当たりする。 | 2Pの命中が1回増え、直近の追加インパルスは3.9。1Pが2Pから離れる方向へ押し戻され、2Pは攻撃前の位置へ滑らかに戻る。 |
| 4 | 攻撃せずに接触させた後、向かい合っている状態でFを押す。必要ならDと左矢印を押し続けて密着させる。 | 接触済みでも1Pの命中が1回増え、追加インパルス2.4が表示される。接触回数が増えることは命中の条件ではない。 |
| 5 | 2体を近づけてFを1回押し、そのまま長押しする。 | その攻撃で命中回数が増えるのは1回だけ。キーリピートで連続命中しない。次の攻撃入力は0.4秒以上経過し、復帰が終わってから有効。 |
| 6 | 相手と離れた初期位置でFを押し、移動キーには触れない。 | 命中回数は増えず、前進後に攻撃前の位置へ滑らかに戻る。空振りでも復帰する。 |
| 7 | 2体を衝突直前まで近づけ、2人でFとEnterをほぼ同時に押す。 | 両者の命中が各1回増え、追加インパルスは1Pが2.4、2Pが3.9。片方の命中で他方が失われない。 |
| 8 | 1PをAで左の境界の外へ動かす。 | 1Pだけ「場外: あり」になり床を抜けて落ちる。2Pは「場外: なし」のまま。1Pの場外表示が重複して変化しない。 |
| 9 | 1Pを左の境界近くへ移動し、外側を向いてFを押す。 | 攻撃で境界を越えた場合も1Pが場外となり、攻撃前の位置には戻らず落下する。 |
| 10 | 命中または場外の後に「最初から試す」を押す。 | 両者が初期位置へ戻り、接触回数と命中回数が0、追加インパルスが「—」、場外が両者とも「なし」に戻る。 |
| 11 | 上部の「トップへ戻る」で離脱し、URLから `/dev/physics` を開き直す。続けて `/dev/babylon` も開く。 | 物理画面が再初期化でき、操作とカウンターが正常に動く。既存のBabylon検証画面も表示できる。 |

攻撃の移動距離はキーを押した時間やフレームレートで変わるため、1Pと2Pの移動距離の数値一致は合否条件にしない。追加インパルス表示と、命中直後に被弾側が離れ攻撃側が押し続けない挙動を確認する。場外になった場合は落下判定を優先し、攻撃前の位置には戻らない。

## 記録

ローカルとVercel Previewの各環境で、OS・ブラウザ名とバージョン・URL・実施日を記録し、各ケースの結果を「成功／失敗／未実施」で残す。失敗時はケース番号、再現操作、画面のスクリーンショットまたは動画、画面のエラー表示とブラウザのConsoleエラーを添える。Previewがまだない場合は「未実施」と記録し、デプロイ後に同じケースを実施する。

F／Enterは検証専用。正式なA／B攻撃、HP、勝敗はこの画面のテスト対象外。
