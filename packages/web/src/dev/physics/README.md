# physics

Issue #6 のPC検証画面 `/dev/physics`。Quick Scanのサンプル形状2体をHavokの剛体として表示する。

1. PCのWebGL2対応ブラウザ、またはVercel Previewで `/dev/physics` を開く。
2. 1PはWASD、2Pは矢印キーで近づける。コマがすり抜けず、接触回数が増えることを確認する。
3. F／Enterで前方へインパルスを加え、衝突時の追加ノックバックを確認する。
4. 片方を半径6.0の境界より外へ動かし、場外表示が一度だけ出て床を抜けて落下することを確認する。
5. 「最初から試す」で配置・接触回数・場外表示が戻ることを確認する。画面を離れて戻っても初期化できることを確認する。

F／Enterは検証専用で、正式なA／B攻撃やHP・勝敗は扱わない。
