# babylon

/dev/babylon：Issue #4 のPC検証画面。WebGL2で Quick Scan の非対称サンプル形状を表示する。

1. Vercel Preview の /dev/babylon をPCで開く。
2. QRをスマホで読み、横持ちでセンサーを許可して基準姿勢を取る。
3. 傾けて移動・旋回し、A/Bで小・中の突進表示を確認する。
4. 「視点確認を始める」でモデルをドラッグして全周を確認する。操作中のカメラ方位は固定。
5. スマホのタブを閉じるか通信を切り、PCで移動停止と切断表示を確認する。

この画面はスマホ1台の描画・入力検証用。物理、ダメージ、勝敗は扱わない。
