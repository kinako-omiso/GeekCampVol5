# host
PC（/host）の本番フローはロビー → スキャン進捗 → 対戦 → 結果。

`HostMatch`が接続・基準姿勢・写真4枚・Maskの確認と版・モデル準備・決着を管理し、スマホへ画面状態を送る。Mask生成は既存Worker、再構成と形状解析は既存Visual Hull/C++ Workerを使う。2体を自動配置し、`BattleScreen`から既存Havokシーンへ入力を接続する。通信断ではモデルを保持して物理・時計を停止し、再準備後3秒で再開する。

`mock/`は既存の検証ページ向けの見本データ。本番フローでは使用しない。

Issue #45の勝利画面には再戦の選択状況カードを表示する。スマホからの選択受信と再戦への遷移は未実装のため、本番では両者とも未選択の表示とし、引き続きPCのボタンでロビーへ戻る。選択表示の確認用ボタンは`/dev/result`へ移した。
